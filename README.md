# Libre AI Personal Knowledge Notebook

## Intended use

Help a person capture, organize and retrieve their own notes, with deliberate control over what they export. Local ownership and inspectable backup behavior are product requirements, not claims that every existing browser path already satisfies them.

## Existing candidates and limits

Earlier sources contain note-domain and cryptographic backup components, along with a backup/restore demonstration. Those candidates do not establish a complete note-taking interface or every browser and WebAssembly path. This documentary candidate admits no working notebook application, encryption guarantee or data-recovery guarantee.

## Proposed contracts

A note identifies its content and changes. An export states exactly what was selected and any retained metadata. A backup and restore result distinguish successful recovery from an invalid or incomplete archive. Personal notes must not become public test material. Canonical exchange formats require admission by Contracts; this document supplies only proposed boundaries.

## Activation criteria

Demonstrate a complete capture, edit, retrieval and controlled-export journey using synthetic notes. Verify backup and restoration, incorrect credentials, damaged input and interrupted operations against the actual cryptographic components. Measure browser behavior and resource limits on the exact supported runtimes. Test storage, deletion and network behavior before claiming locality, confidentiality or recoverability.

The complete journey described above is a criterion for activating the product. A candidate module may be qualified and admitted separately for its own explicit scope, with its own consumer and evidence. Neither that module admission nor the documentary existence of this repository requires a complete Missions journey or completion of other future products.
