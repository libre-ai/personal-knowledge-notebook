# Libre AI Personal Knowledge Notebook

Capture your notes, organize them and find useful information again while choosing what you share. This proposed product is for people building a personal collection of knowledge who want deliberate control over their notes and exports.


## Intended uses

- Write and revise notes as your understanding develops.
- Find information in your collection without having to remember where you put it.
- Export a chosen selection and understand what a backup would allow you to recover.

**Today:** source code and tests are present; local integration is underway. See the [development guide](docs/DEVELOPMENT.md) for setup and verification status.
